Android面试

Android P7 级别面试题（对标阿里P7，侧重架构、深度原理、复杂问题解决、团队能力）

整体分基础深度、架构设计、性能优化、跨端/底层、项目实战、团队与技术管理6大模块，贴合P7对技术深度+架构能力+落地能力的核心要求。

一、基础与核心原理（深挖底层，拒绝表面使用）

1. 请完整讲清 Activity 启动流程（从 startActivity 到 handleLaunchActivity，涉及 AMS、ATMS、进程通信细节）。

2. Handler 机制底层原理：MessageQueue 存储结构、NativePollOnce 阻塞唤醒原理、IdleHandler 使用场景与原理。

3. Binder 原理：Binder 驱动原理、一次拷贝、AIDL 底层实现、多进程通信中的稳定性问题如何解决。

4. Android 内存管理：GC 机制、内存抖动、内存泄漏本质，LeakCanary 核心检测原理。

5. Android 事件分发机制：从 Activity -> ViewGroup -> View 完整流程，onInterceptTouchEvent、onTouchEvent、requestDisallowIntercept 实战冲突解决。

6. Jetpack 核心组件原理

◦ ViewModel 为什么能屏幕旋转不重建、onCleared 调用时机。

◦ LiveData 黏性事件、数据倒灌问题成因与解决方案。

◦ Lifecycle 如何实现生命周期感知，自定义 LifecycleOwner 场景。

二、架构设计与工程能力（P7核心：可扩展、可维护、高可用）

1. 你在项目中如何做 架构选型与演进？MVVM/MVI 对比，为什么选当前架构，解决了什么痛点。

2. 如何设计 组件化/模块化架构：组件通信方案（ARouter 原理）、组件解耦、独立调试、版本管理、依赖闭环问题。

3. 网络层架构设计：统一封装、重试机制、缓存策略、请求合并、HTTPS 证书校验、弱网优化、幂等性处理。

4. 如何设计 图片加载框架（对比 Glide、Coil），三级缓存原理、内存缓存淘汰策略、OOM 预防机制。

5. 请设计一个 通用弹窗/Toast 组件，解决队列管理、生命周期绑定、内存泄漏、多窗口兼容性问题。

6. 如何做 ABI 适配、多渠道打包、插件化/热修复原理与落地风险控制。

三、性能优化（P7必备：全维度优化+线上问题治理）

1. 启动优化：冷启动/温启动/热启动区别，黑白屏问题、启动耗时检测、异步初始化方案（StartUp 原理）、延迟加载策略。

2. UI 流畅度优化：卡顿检测（Choreographer 原理）、掉帧原因、过度绘制优化、RecyclerView 卡顿优化、布局优化方案。

3. 内存优化：线上 OOM 监控方案、图片内存优化、大对象管控、内存泄漏自动化检测与修复闭环。

4. 包体积优化：资源混淆、图片压缩、无用代码/资源清理、ABI 裁剪、插件化缩减体积。

5. 线上稳定性治理：Crash 监控、ANR 监控与分析、异常上报聚合、灰度发布、故障降级方案。

四、跨端、底层与前沿技术（体现技术广度）

1. Flutter/React Native 与原生混合栈：通信机制、内存问题、渲染差异、混合栈稳定性优化。

2. Android 底层相关：Linux 进程/线程模型、JNI 优化、SO 加载原理、崩溃捕获底层原理。

3. Kotlin 深度：协程原理（Continuation、挂起函数）、Flow 背压、与 RxJava 对比、协程内存泄漏场景。

4. 鸿蒙/车载/折叠屏：多窗口适配、差异化开发、兼容性架构设计思路。

五、项目实战与复杂问题解决（考察真实落地能力）

1. 介绍一个你主导设计的核心模块，讲清：业务背景、技术难点、架构设计、优化效果、数据指标。

2. 遇到过最复杂的线上问题是什么？如何定位、分析、解决、复盘、建立预防机制。

3. 如何做 技术方案评审：如何评估技术风险、兼容历史代码、平衡开发成本与迭代效率。

4. 多团队协作开发时，如何解决 代码冲突、需求变更、版本对齐、技术债务问题。

六、团队与技术管理（P7 不只是写代码，还要带方向）

1. 如何带领中级/初级工程师做技术攻坚、代码评审、技术成长。

2. 如何推动技术优化落地（如架构重构、性能优化），平衡业务需求与技术基建。

3. 对 Android 未来技术趋势的理解，如何做团队技术栈规划与预研。

4. 如何制定 编码规范、CI/CD 流程、自动化测试体系，提升团队研发效率。
